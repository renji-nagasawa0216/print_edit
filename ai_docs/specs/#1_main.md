# main 名刺マスタ・PDF作成・取込&作成の分離（段階①②）

## 目的
取り込み（名刺の切り出し・登録）と PDF 作成を分け、名刺マスタから複数名刺を自由に配置した PDF を作り、履歴からシート単位で再印刷・調整し、印刷待ちをまとめて印刷・破棄できるようにする。

## 対象外
- 名刺画像の上へのテキスト配置・フォント・文字の太さと濃淡（R10〜R10-5。J17=B で段階③として次の /go）
- 名刺マスタ削除・一括破棄の復元画面（J11=A）
- PDF 描画ロジック core/pdf.py・core/layout.py の変更（M30。デグレ確認のみ）
- プリンター・印刷オプション・検出・取込設定の挙動変更（M32。全体設定へ移すだけ）
- 1名刺1PDF の名刺切替プレビューの画面イメージ追加（J20=A。決定表どおり実装し mock 08 は追加しない）

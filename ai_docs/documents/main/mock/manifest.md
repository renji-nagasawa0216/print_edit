## 原因メモ
- emulate でビューポートを切り替えるとページがリロードされ、DOM 差し替え・タブ状態・詳細展開が消える（手順書の想定と異なる）。対策: 各撮影の直前に reload → inject.js を流し直した。第2バッチも同様にすること
- before 撮影で、emulate 直後に表示タブを戻さず撮ってしまい履歴一覧が写る事故が2回あった（印刷待ち pc、設定 sp、詳細展開 sp）。撮り直し済み。画像の実高と scrollHeight×dpr の一致で確認
- sp の設定系画面（設定作成の before・全体設定 の before/after）は既存の text 入力（width:24em）で横スクロールが出る（scrollWidth 556、画像幅 1668px = 556×3）。これは現行実装由来で、今回の差し替えで起きたものではない。設定作成 after は幅 390 に収まる
- sp のヘッダーは 7 タブが入り切らないためモックで `header{flex-wrap:wrap}` `nav{display:flex;flex-wrap:wrap;gap:4px}` を足している。実装時も CSS 変更が必要
- sp の設定作成・スロット図拡大は SVG が幅 517px で 390px を超える（オーバーレイ内で横スクロールの想定）。実装時は幅に収める調整が要る
- 設定作成 pc の「面付けプレビュー」は position:sticky のため、fullPage 撮影ではスクロール位置次第で位置が実機とずれる可能性がある

### 原因メモ（第2バッチ）
- 現行 layout preview API の slots が cards_per_sheet に依存し2件しか返らず、最初の描画でスロット2個しか出なかった。inject 内で先頭スロットの寸法から capacity 分を再計算して解決

- sp 拡大の SVG 幅は 368px（390 に収まる）、全 sp 画面 scrollWidth=390（横スクロールなし）

承認: 「推奨で問題なく、これで承認とします」（J1〜J9 を AI 推奨で確定）

### この絵で確定した論点

AI 判断で絵のまま確定: タブの並び順（01 の絵）／「今すぐ取り込み」は「取込&作成」に置換／印刷待ちの行内ボタンは一括操作と併置／既定値「既定」は削除不可／名刺名は保存ボタンで保存／スロット差し替えはクリック→選択／一括印刷の失敗シートは単体の「印刷する」が失敗したときと同じ扱い（先例 src/print_edit/pipeline.py `print_sheet`）／登録待ちの「取込&作成で使用済み」「移行分」バッジを付ける

### 絵に反映されていない仕様（承認時に追記）
- 全体設定の「印刷」欄には、プリンタの画質（print-quality）と「そのほかの印刷オプション」（11.10）を現行どおり残す。モックはサンドボックスのプリンタ名が実在せず表示されなかっただけ
- 05 の値（プリンタ名・lp オプション・寸法許容差など）はサンドボックスの値。移行で現在の値は変わらない
- 設定作成のスロット図はモックの都合で2枠のみ描画。実装は容量分（例 10 枠）を描く
- sp の拡大オーバーレイで説明文が背景タブと重なって写っているのは絵の粗さで、仕様ではない
- 上書き保存の確認ダイアログは文言のみ／検索絞り込み・スロット差し替え後の表示・ホイール拡大縮小は静止画で未表現

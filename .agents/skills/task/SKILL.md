# タスク定義

題名、目的、対象範囲、参照資料、測定可能な完了条件、担当や先行タスクがあればそれを記録する。未確定事項は明示する。指定されたタスク管理方法を使い、未指定でファイル化を求められた場合は作業ルートの `tasks/` に一意な名前の Markdown を作る。既存タスクの状態更新は現在の状態と完了根拠を確認してから行う。

共有ハーネスがある場合は作業ルートで `python3 .codex/hooks/harness.py task add <ID> "<題名>" "<完了条件>"` を利用できる。ID と担当者識別子は英数字・ハイフン・アンダースコアを使う。`task list` で確認し、明示されたタスクを `task claim <ID> <担当者>` で引き受ける。担当者は `task done <ID> <担当者>` で完了、または `task release <ID> <担当者>` で未着手に戻す。セッション開始時に未着手IDが通知される。

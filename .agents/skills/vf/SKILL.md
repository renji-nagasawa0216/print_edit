# 検証

- 要件と対象リビジョン、検証環境、テストデータ、プロジェクト既定の検証手順を確認する。
- 通常の入口からケースを実行し、期待と実測を照合する。画面操作が必要かつ実行環境がある場合は、利用可能なブラウザで主要な動線を検証する。
- ケースID、コマンドまたは操作、結果（成功・失敗・未実行）、根拠を記録する。環境要因と実装の失敗を観測結果で区別する。
- 期待値に疑義があれば要件と照合する。条件不足で確認できない項目は、必要な条件とともに未実行として返す。

# 要件定義

- 依頼、指定の資料、関連する既存挙動を確認する。確認できた事実と仮定を明記する。
- 要件にIDを付け、対象者、入力、挙動、対象外、既存互換性、画面への影響を必要な範囲で記録する。
- 判断が必要な項目ごとに、資料で確定できない点、選択肢、推奨と理由をまとめる。未回答は未確定として残す。
- 合意した要件と観測可能な受入条件を返す。保存先が指定された場合はそこへ書く。

`templates/judge.md` が利用できる場合は判断待ちの提示に使う。プロジェクト固有の用語を記録する場合は既存用語集か `templates/terminology.md` を参照する。

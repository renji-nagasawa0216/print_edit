# 引き継ぎ

ユーザー指定の保存先を使う。未指定なら作業ルートの `handoffs/` に日付と用途を含む新規 Markdown を作成する。同名があれば枝番を付ける。該当する前回の記録があればリンクする。

1. 作業ディレクトリ、ブランチ、対象範囲
2. 引き続き有効なユーザーの制約（必要箇所を原文引用）
3. 確定事項と参照先
4. 変更内容と検証結果
5. 未解決事項（問いごとに安定したIDと状態）
6. 残作業と再開時の最初の確認

認証情報は記録から除く。最後に保存先を返す。セッションの切り替えは利用者が行う。

作業ルート内に保存した引き継ぎ文書は、ルートから `python3 .codex/hooks/harness.py handoff <文書パス>` で登録する。次回の SessionStart で同じブランチに登録された文書への参照が渡る。
